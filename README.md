# Unlock the Safe

A PixiJS + TypeScript mini-game where you crack a vault combination by turning the handle.

## Usage 🛠️

1. Clone repository `npx degit https://github.com/MimiM03/unlock-the-safe-mini-game.git new-folder`

2. Navigate to the new directory and install the project dependencies using `npm install`

### Run

```bash
npm start
```

Opens a Vite dev server (default: [http://localhost:3000](http://localhost:3000)).

### Build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Controls

- **A** / click left side of the safe — turn handle counterclockwise
- **D** / click right side of the safe — turn handle clockwise

The secret combination is logged in the browser console when a new code is generated.
